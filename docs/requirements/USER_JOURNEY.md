# Primary user journey

1. Discover MarketScope and understand that it is a research product, not a broker.
2. Sign in through the selected managed identity provider (not wired in this starter).
3. Enter the research workspace and search by company name, symbol or supported identifier.
4. Resolve the issuer/listing/instrument identity. If ambiguous, show candidates and require selection.
5. Open the company dossier and review coverage, reporting basis and data-as-of status.
6. Inspect financial statements and metrics; open definitions, formula, inputs and limitations.
7. Inspect evidence: source, publication date, retrieval time, transformation and quality state.
8. Explore peer context, events and counter-evidence as these modules are implemented.
9. Create a research note with thesis, concerns and unresolved questions.
10. Save a snapshot containing fact versions, formula versions, assumptions and source references.
11. Return later and compare the saved snapshot with current facts, distinguishing data revisions from formula changes.

## Alternate journeys
- Screener: select universe → apply filters → inspect results → open dossier → save screen.
- Peer comparison: select 2–5 compatible companies → align periods and reporting basis → compare → save.
- AI explainer (future/gated): rights check → retrieve permitted evidence → generate claim-level citations → verify → abstain if evidence is weak.
