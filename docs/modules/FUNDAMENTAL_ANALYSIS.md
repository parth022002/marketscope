# MarketScope.io — Fundamental Analysis Module

## 1. Overview
The Fundamental Analysis module powers the 6-pillar fundamental scorecard, financial statements viewer, and peer valuation comparisons on each stock's research hub.

## 2. 6-Pillar Scorecard Methodology
1. **Valuation**: P/E, P/B, EV/EBITDA, Price-to-Sales compared against 3-year historical medians and sectoral averages.
2. **Growth**: 3-year and 5-year CAGR of Revenue, Operating Profit, and Net Income.
3. **Profitability**: Operating Margin (OPM), Net Profit Margin, Return on Equity (ROE), and Return on Capital Employed (ROCE).
4. **Financial Health**: Debt-to-Equity, Interest Coverage Ratio, Current Ratio, and Altman Z-Score distress metrics.
5. **Red Flags**: Auditor qualifications, pledged promoter shares, promoter holding reduction, high contingent liabilities.
6. **Ownership Structure**: Promoter holding, Foreign Institutional Investors (FII), Domestic Institutional Investors (DII), and Retail shareholding trends.
