# Global Stock Exchange Coverage Report

## 1. Executive Summary

This report establishes the verified exchange coverage of MarketScope.io. Rather than claiming universal real-time data across every illiquid venue, MarketScope.io classifies every exchange venue with transparent status labels: `VERIFIED`, `IMPORTED`, `PARTIALLY_AVAILABLE`, or `LICENCE_REQUIRED`.
