# MarketScope.io — Design System Specification

## 1. Visual Direction
A modern financial technology aesthetic combining the analytical precision of institutional financial terminals with the clean minimalism of premium SaaS workspaces.

---

## 2. Design Tokens

### Color Palette (Dark Theme - Primary)
- **Background Base**: `#070E1B` (Deep obsidian navy)
- **Surface Panels**: `#0A1428` (Dark slate container)
- **Elevated Surfaces**: `#0F1D38` (Card & modal background)
- **Border Subtle**: `rgba(30, 58, 102, 0.4)`
- **Border Active**: `rgba(56, 189, 248, 0.5)`
- **Text Primary**: `#F8FAFC` (High contrast crisp white)
- **Text Secondary**: `#94A3B8` (Slate text)
- **Text Muted**: `#64748B` (Secondary captions & timestamps)

### Financial Status Indicators
- **Positive / Bullish**: `#10B981` (Emerald green, `+X.XX%`)
- **Negative / Bearish**: `#F43F5E` (Rose red, `-X.XX%`)
- **Neutral / Flat**: `#64748B` (Slate grey)
- **Warning / Alert**: `#F59E0B` (Amber gold)
- **Information / Verified**: `#38BDF8` (Sky blue)

### Typography
- **Primary Interface**: Inter (`font-sans`, weights 400, 500, 600, 700, 800)
- **Tabular Figures**: JetBrains Mono / Inter Tabular Numerals (`font-mono`, `font-variant-numeric: tabular-nums`)
- **Line Heights**: Relaxed headings (1.2), compact data grids (1.0 - 1.25).
