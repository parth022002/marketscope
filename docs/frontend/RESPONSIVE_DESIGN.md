# MarketScope.io — Responsive Design Specification

## 1. Breakpoint Architecture
- **Desktop (>= 1280px)**:
  - Fixed sidebar (256px expanded / 72px collapsed).
  - Main research viewport max-width 1600px with multi-column analytical grids.
  - Multi-chart split layouts (2H, 2V, 4 Grid).
- **Laptop (1024px - 1279px)**:
  - Compact sidebar (72px) with floating tooltips.
  - 2-column dashboard grids.
- **Tablet (768px - 1023px)**:
  - Collapsed icon-rail navigation.
  - Horizontally scrollable financial ratio tables with sticky first column.
  - Single/dual chart viewport.
- **Mobile (< 768px)**:
  - Off-canvas touch drawer with hamburger menu button.
  - Sticky top header with quick search trigger.
  - Single-column stacked financial metrics.
  - Full-width touch-optimized Lightweight Charts canvas.
