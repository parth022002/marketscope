# MarketScope.io — End-to-End User Journey Specification

## 1. Product Journey Philosophy
"Professional financial intelligence, made simple."

The user journey is structured to deliver immediate value within 3 clicks, allowing novice investors to understand the market pulse while enabling professional quantitative analysts to perform deep fundamental and technical research.

---

## 2. 12-Step Progressive User Flow

1. **Discovery & Onboarding**:
   - User arrives at MarketScope.io.
   - The subtle 3D perspective financial grid and market ticker immediately communicate real-time market pulse and institutional credibility.
2. **Market Orientation**:
   - The overview dashboard displays Nifty 50, Sensex, and global market movements, sector performance, and advance/decline breadth above the fold.
3. **Instant Universal Discovery**:
   - User hits `Cmd+K` or taps search to find any Indian or international security using company name, ticker symbol, or ISIN.
4. **Company Dossier Access**:
   - Selecting a security routes to `/company/[symbol]`.
   - Clear quotation, session change, and verified exchange timestamp are prominently displayed.
5. **Fundamental & Valuation Study**:
   - Contextual tabs allow seamless navigation between 15 golden financial ratios, quarterly balance sheets, and DCF sensitivity models.
6. **Technical & Chart Workspace**:
   - With a single click on "Open Chart", the user enters the professional `/charts` terminal with Lightweight Charts, drawing tools, and 10 technical indicators.
7. **Unified AI Synthesis**:
   - User reviews the MarketScope Unified Intelligence report (`/intelligence`), examining fundamental, valuation, technical, risk, and regime model outputs.
8. **Evidence Verification**:
   - Expandable evidence drawers display primary exchange notices and regulatory filings backing up claims.
9. **Watchlist Curation**:
   - User adds the company to their custom watchlist with custom price targets.
10. **Price Alert Configuration**:
    - User configures threshold alerts via `/alerts`.
11. **Virtual Execution & Portfolio Allocation**:
    - User tests investment hypotheses in the simulated `/portfolio` desk.
12. **Saved Research & Monitoring**:
    - Research notes, saved chart layouts, and historical screens persist in `/workspace`.
