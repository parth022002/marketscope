# MarketScope.io — Licenses Directory

This directory stores copies and references for open-source licenses, data provider terms, and infrastructure service agreements governing the MarketScope.io application.

---

## Directory Organization

- **`frontend/`**: Licenses for user interface, client-side frameworks, and bundling tooling (Next.js, React, Tailwind CSS, TypeScript, Lightweight Charts).
- **`backend/`**: Licenses for server-side engines, API frameworks, database drivers, and calculation packages (FastAPI, Uvicorn, Pydantic, SQLAlchemy, Psycopg).
- **`assets/`**: Font licenses (Geist SIL OFL 1.1) and icon licenses (Lucide ISC).
- **`services/`**: Terms of service summaries for cloud hosting, authentication, database, and market data providers.
